## Commands
- Dev: `npm run dev`
- Build: `npm run build`
- Test: `npm test`
- Typecheck: `npm run typecheck`
- Lint: `npm run lint`

## Working method
Implement ONE phase at a time from `docs/06-implementation-plan.md`.
Stop at the end of a phase and report which acceptance criteria pass.
Never start the next phase unless asked.
